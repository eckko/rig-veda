# Glossary: fixed renderings for the Rigveda layers (extended by the reviewer, not the drafter)

Rigveda hymns. Do not import later commentary (Sayana etc.) or later tradition; translate what the verse says.
- ṛṣi = sage (ऋषि); deva = god (देव); devatā not used inside translations
- Agni = Agni (अग्नि), Indra = Indra (इन्द्र), Soma = Soma (सोम); proper names in plain IAST in English (Agni, Indra, Varuṇa, Mitra)
- yajña = sacrifice (यज्ञ); hotṛ = Hotṛ priest (होता); havis = oblation (हवि); stoma = praise (स्तोम); manman, gir = hymn/praise
- dyāvāpṛthivī = Heaven and Earth (द्यावापृथिवी); asura (in the Ṛgveda) = lord/god, gloss "asura"
- Aṅgiras = Aṅgiras (अङ्गिरस्); Maruts = Maruts (मरुत्)
- Hindi: names in Devanagari; no Latin letters.
